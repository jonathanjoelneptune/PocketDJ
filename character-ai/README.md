# PocketDJ Character AI (WP2B)
Separate Vercel project, root directory `character-ai`. Do not change PocketDJ's GitHub Pages deployment.
1. Import the PocketDJ repository into Vercel as a NEW project with root directory `character-ai`, framework Other, no build command.
2. Set sensitive production variables OPENAI_API_KEY (a project API key with Images access and billing) and STUDIO_ACCESS_TOKEN (random 32+ character secret). Set a provider project spending limit/alerts appropriate to your usage; the endpoint does not implement distributed rate limiting. One request generates one image. Never commit these values.
3. Deploy, copy the actual HTTPS endpoint `https://<your-project>.vercel.app/api/generate`, and enter it in Character Studio's AI Designer. Enter the studio access token (not the OpenAI key). The token stays in memory and is not saved. Click Check connection. GET is free and verifies server configuration and the studio access token, not provider authentication.
4. Generate one candidate explicitly. Each request may incur API charges, including failed/cancelled requests. There is no automatic generation or retry.
5. Use the candidate in Reskin lab, align and inspect, then resolve hidden layers independently. The model does not guarantee exact registration; the deterministic pixel lock controls the final geometry.
The browser sends the masked 1024-square source pose, character description and optional identity reference to the configured endpoint. The service forwards these to OpenAI Images edits. The server enforces a fixed model, image size, one image per call, allowed origin and secret authentication, and request/output size caps. CORS is not authentication. Do not share the studio access token publicly. Rotate it if exposed. Generated files stay in the browser workspace. No production runtime changes.
