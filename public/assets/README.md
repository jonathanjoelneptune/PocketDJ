# Runtime assets

Drop polished runtime art here. Keep source zips, PSDs, RARs, and generation experiments outside `public` so GitHub Pages only ships what the app needs.

Suggested folders:

- `poses/idle/`
- `poses/active/`
- `poses/transition/`
- `room/`
- `ui/`

The starter app uses CSS fallback poses, so it will run before final PNGs are added.
