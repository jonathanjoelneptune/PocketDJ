Proposed production architecture

Path typeRecommended methodWhy
Within a scratch familyExisting independent arm rigAlready smooth. Keep as-is, no extra bridge clips.
Similar scratching familiesShared hands-on-decks bridge + 1–2 authored sleeve framesSmall shoulder/arm changes, maintain an anchored torso and face.
Scratch ↔ standing/vibeHand-drawn 3–5 pose phases + shoulder repairCrossed arms and raised hands cannot be formed by warping a scratch rig.
Idle/rest ↔ activeRest-to-ready bridge clipsRe-use authored rest/ready exits and entries instead of authoring all pairs.
I1 lean-back restFull illustrated standing/sitting transitionLeg and torso geometry move; rigid warps will look malformed.
Any playing pose → A41Common record-pickup anticipationConverge on a single hands-to-center pickup pose before A41.
A41 → cinematic branch → placementFixed, hand-drawn consecutive framesProtect real record trajectory and four-corner album perspective.
Final placement → activeCommon hand-return bridgeFinish the record gesture before changing the performance family.
Speaking entry/exitChest/shoulder and head-orientation bridgesSpeech is an interrupt; supports rapid return without malformed frames.
Do not use whole-body affine warps, mesh interpolation, or slow alpha crossfades in production. They can create duplicate hands/faces, blurry pixel edges, and detached hoodie sleeves.

Recommended authoring standard: 582×652 RGBA; character silhouette fixed to the static table coordinate system; integer-pixel drawing; unchanged deck artwork; no eye/face shearing; explicit arm-over-record ordering; reversible paths only if the motion still makes anatomical sense.
