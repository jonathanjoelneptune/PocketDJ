# Pocket DJ Dynamic Scratch Loop Update Changelog

<span style="color:#16a34a;">Added:</span> Restored the standard scratch-focused quick performance loops:
- `a10.png` / `a10-2.png`
- `a4.png` / `a4-2.png`
- `a14.png` / `a14-2.png`
- `a44.png` / `a44-2.png` / `a44-3.png`
- `a47.png` / `a47-2.png` / `a47-3.png`
- `a48.png` / `a48-2.png` / `a48-3.png`

<span style="color:#16a34a;">Added:</span> Per-loop dwell timing so the DJ can stay inside a scratch loop for either a short burst or a longer organic stretch.

<span style="color:#16a34a;">Changed:</span> Scratch frame timing is randomized within each loop, so the DJ can scratch with varied milliseconds between frames instead of a robotic cadence.

<span style="color:#16a34a;">Changed:</span> Three-frame scratch loops now use a back-and-forth sequence such as `a44 → a44-2 → a44-3 → a44-2` for smoother repeated scratching.

<span style="color:#16a34a;">Changed:</span> The frame debug utility now shows the active loop dwell timing range.

<span style="color:#dc2626;">Removed:</span> The overly limited active loop pool from the previous chill-scratch pass.
