# Pocket DJ Marquee Staggered Transition Changelog

<span style="color:#16a34a;">Changed:</span> On song changes, the old title now slides off to the left and the new title slides in from the right.

<span style="color:#16a34a;">Changed:</span> Artist text now follows the title with a delayed transition, creating a staggered two-line marquee effect.

<span style="color:#16a34a;">Changed:</span> Artist text is larger and easier to read.

<span style="color:#16a34a;">Changed:</span> Long artist drift now travels across the full marquee width instead of behaving like the box is only partially wide.

<span style="color:#dc2626;">Removed:</span> The previous song-change fade/flash-only transition.
