# Pocket DJ Side Panel Playback Buttons Cleanup Changelog

<span style="color:#16a34a;">Changed:</span> Side-panel playback buttons now use a cleaner compact design instead of trying to match the floor controls.

<span style="color:#16a34a;">Changed:</span> Play/pause is now a larger soft circular control sized for the utility panel.

<span style="color:#16a34a;">Changed:</span> Previous/next now use clean chevrons that scale better than the previous glyphs.

<span style="color:#16a34a;">Changed:</span> Shuffle and repeat now show compact `SHUF` and `REP` labels for better readability at panel size.

<span style="color:#16a34a;">Changed:</span> Active shuffle/repeat state is clearer but still subtle.

<span style="color:#16a34a;">Changed:</span> Volume row spacing was tightened to match the cleaned button row.
