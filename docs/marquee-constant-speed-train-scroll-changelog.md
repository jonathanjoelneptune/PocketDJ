# Pocket DJ Marquee Constant-Speed Train Scroll Changelog

<span style="color:#16a34a;">Changed:</span> Long title and artist rows now scroll at a constant visual speed.

<span style="color:#16a34a;">Changed:</span> Overflow text now repeats in a train pattern, so the next copy enters from the right before the previous copy fully leaves left.

<span style="color:#16a34a;">Added:</span> Separator icon `✦` between repeated marquee copies.

<span style="color:#16a34a;">Changed:</span> Scroll duration is dynamically calculated from rendered text width so longer text travels farther without changing speed.

<span style="color:#dc2626;">Removed:</span> Full exit-left / re-enter-right reset cycle for long rows.
