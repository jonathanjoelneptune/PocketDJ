# Pocket DJ Floor Controls Font and Progress Bar Changelog

<span style="color:#16a34a;">Changed:</span> Floor control button text/icons now use the same pixel font family as the marquee.

<span style="color:#16a34a;">Changed:</span> Control colors were shifted from cool gray to a warmer smoky amber-gray so the controls stay subtle while matching the room better.

<span style="color:#16a34a;">Added:</span> A subtle song progress bar under the floor controls spanning from previous through the three-dot button.

<span style="color:#16a34a;">Added:</span> Progress bar updates from the current Spotify track progress without showing timestamps.

<span style="color:#16a34a;">Changed:</span> Floor control panel height and grid layout were adjusted to make room for the progress bar while keeping the inset floor-console feel.
