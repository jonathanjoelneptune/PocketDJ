# Pocket DJ Lyrics Readability and Active Wrap Polish

<span style="color:#16a34a;">Changed:</span> Moved the lyric boundary defaults lower on the ceiling.

<span style="color:#16a34a;">Changed:</span> Inactive lyrics are dimmer so they read as ceiling projection/context instead of competing with the active lyric.

<span style="color:#16a34a;">Changed:</span> Active lyric now more closely matches the marquee: crisp amber text, screen-facing orientation, and a subtle dark backing strip.

<span style="color:#16a34a;">Added:</span> Optional active lyric layout utility with Single line and Two-line wrap modes.

<span style="color:#16a34a;">Changed:</span> Two-line wrap is the default so longer active lyrics do not feel cramped or clip as easily.

<span style="color:#16a34a;">Changed:</span> Vertical and horizontal marquee lyric animations are stronger and more visually distinct.

<span style="color:#16a34a;">Changed:</span> Room utility storage key bumped to `pocketdj-room-utility-v2` and old v1 settings are migrated for speakers/room filters only. This prevents stale saved lyric settings from blocking the new defaults.
