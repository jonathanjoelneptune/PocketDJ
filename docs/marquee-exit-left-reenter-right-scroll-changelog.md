# Pocket DJ Marquee Exit-Left / Re-enter-Right Scroll Changelog

<span style="color:#16a34a;">Changed:</span> Long title and artist rows no longer fade out and reset.

<span style="color:#16a34a;">Changed:</span> Long rows now hold, scroll left to reveal the hidden end, continue fully off the marquee to the left, then re-enter from the right and settle back to the starting position.

<span style="color:#16a34a;">Changed:</span> Artist row still starts its cycle slightly after the title row so both rows are not moving in perfect lockstep.

<span style="color:#dc2626;">Removed:</span> Fade-reset behavior for long marquee rows.
