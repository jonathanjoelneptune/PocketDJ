# Pocket DJ Right-Edge Room-Relative Panel Sizing Changelog

<span style="color:#16a34a;">Changed:</span> The right utility panel now anchors to the far right edge of the 16:9 room instead of floating based on viewport sizing.

<span style="color:#16a34a;">Changed:</span> Panel width is now fixed at `25%` of the room width so it stays consistent relative to the room at small and fullscreen sizes.

<span style="color:#16a34a;">Changed:</span> Panel top, max height, padding, border radius, now-playing card, artwork, controls, and text sizing are all room-relative.

<span style="color:#16a34a;">Changed:</span> The panel closes by sliding off from the room edge while keeping the same room-relative geometry.
