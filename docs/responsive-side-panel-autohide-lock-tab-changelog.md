# Pocket DJ Responsive Side Panel Auto-Hide, Lock, and Tab Changelog

<span style="color:#16a34a;">Changed:</span> Side panel width is now dynamic instead of always 25% of the room. It stays around 25% at fullscreen, but can grow toward 50-75% on smaller windows so it remains readable.

<span style="color:#16a34a;">Added:</span> A side-panel lock button between `Connected` and the close button. When locked, the side panel stays open.

<span style="color:#16a34a;">Added:</span> Side panel auto-hide behavior. The panel remains open on hover or when locked, and hides after 10 seconds otherwise.

<span style="color:#16a34a;">Added:</span> A polished right-edge hover tab with a music note and left arrow. Hovering or clicking it opens the side panel.

<span style="color:#16a34a;">Fixed:</span> Bottom-left floor controls lock icon vertical centering.
