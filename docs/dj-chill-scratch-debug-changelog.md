# Pocket DJ Chill Scratch Animation Update Changelog

<span style="color:#16a34a;">Changed:</span> Active DJ behavior is now calmer and scratch-focused.

<span style="color:#16a34a;">Changed:</span> Quick loops are now limited to:
- `a10.png` / `a10-2.png`
- `a4.png` / `a4-2.png`
- `a1.png` / `a2.png` / `a3.png`

<span style="color:#16a34a;">Changed:</span> `a11` and `a11m` cinematic loops are now reserved for the near-end-of-song trigger only.

<span style="color:#16a34a;">Added:</span> Bottom-left animation utility button showing the current DJ sprite filename, mode, loop, control mode, and cinematic state.

<span style="color:#dc2626;">Removed:</span> The following frames from normal active loop use: `a15`, `a20`, `a21`, `a22`, `a23`, `a24`, `a25`, `a32`, `a38`, `a5`, `a6`, `a7`, `a8`, and `a9`.

<span style="color:#dc2626;">Removed:</span> Hype/crowd loops from the normal active pool so the DJ stays more unassuming.
