# Pocket DJ Floor Controls Subtle Style and Previous Restart Changelog

<span style="color:#16a34a;">Changed:</span> Floor control styling is now more subtle gray/charcoal instead of bright yellow.

<span style="color:#16a34a;">Changed:</span> Previous and next buttons now use distinct `⏮` and `⏭` icons so the play button is easier to distinguish.

<span style="color:#16a34a;">Changed:</span> Play/pause now uses `▶` and `Ⅱ` for clearer visual separation.

<span style="color:#16a34a;">Changed:</span> Pressing Previous restarts the current track when playback is more than 3 seconds in.

<span style="color:#16a34a;">Changed:</span> Pressing Previous again near the beginning of the song goes to the previous track.

<span style="color:#16a34a;">Added:</span> Spotify seek helper for restarting the current track.
