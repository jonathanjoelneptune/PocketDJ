# Pocket DJ Idle Timing and Bounce Fix Changelog

<span style="color:#16a34a;">Changed:</span> Idle now uses only the approved pose list: `i6.png`, `i7.png`, `i8.png`, `i9.png`, `i1.png`, `i10.png`, `i11.png`, and `i12.png`.

<span style="color:#16a34a;">Changed:</span> Idle pose changes now happen much more slowly, with each idle pose held for roughly 30 to 60 seconds.

<span style="color:#16a34a;">Changed:</span> Paused mode now uses the same calm idle pose family and holds poses for roughly 25 to 50 seconds.

<span style="color:#16a34a;">Changed:</span> Spotify polling on a visible page now runs about every 2.5 seconds so active/idle/paused state transitions happen faster.

<span style="color:#dc2626;">Removed:</span> The automatic up/down bounce animation on the DJ/table when music starts playing.

<span style="color:#dc2626;">Removed:</span> Unapproved idle frames from the idle and paused pose pools.
