# Pocket DJ Floor Controls Room-Relative Scale and Speaker Size Changelog

<span style="color:#16a34a;">Changed:</span> Floor playback controls now use room-relative width, height, gap, icon, and progress-bar sizing so they scale with the fixed 16:9 room instead of feeling tiny at fullscreen.

<span style="color:#16a34a;">Changed:</span> Previous, play/pause, and next icons are larger and more consistent with each other.

<span style="color:#16a34a;">Changed:</span> Speaker cabinet base width is now room-relative using `--speaker-base-width` instead of the previous clamped width.

<span style="color:#16a34a;">Changed:</span> Speaker base width default is set to `7.1%` so the speakers maintain the larger elbow-height presence when the room is fullscreen.
