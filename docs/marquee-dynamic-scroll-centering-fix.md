# Pocket DJ Marquee Dynamic Scroll and Centering Fix

<span style="color:#16a34a;">Changed:</span> Marquee overflow scroll is now calculated from the actual rendered text width versus the marquee viewport width.

<span style="color:#16a34a;">Changed:</span> Long title and artist rows now pan far enough to reveal the full text, including long artist lists.

<span style="color:#16a34a;">Changed:</span> Short title and artist rows remain centered.

<span style="color:#16a34a;">Changed:</span> Long rows align from the left edge before panning, which prevents the cropped/partial-width scrolling behavior.
