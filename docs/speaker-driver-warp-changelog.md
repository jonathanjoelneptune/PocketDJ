# Pocket DJ Speaker Driver Warp Changelog

<span style="color:#16a34a;">Added:</span> Speaker driver warp layer that clips a duplicate of the speaker image to the driver area and scales it from the cone center.

<span style="color:#16a34a;">Changed:</span> Speaker pulse now reads as physical speaker cone movement instead of a light glow.

<span style="color:#16a34a;">Changed:</span> Speaker pulse X/Y/size defaults were updated to the latest tuned values: X `53.0`, Y `50.4`, size `48.2`.

<span style="color:#dc2626;">Removed:</span> The bright light-style pulse effect from the speaker driver area.
