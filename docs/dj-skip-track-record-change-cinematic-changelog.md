# Pocket DJ Skip Track Record-Change Cinematic Changelog

<span style="color:#16a34a;">Added:</span> Manual next/previous track changes now trigger the same A11/A11m record-change cinematic used near the end of a song.

<span style="color:#16a34a;">Changed:</span> Left/right cinematic alternation is preserved for skipped/previous tracks and near-end-of-track triggers.

<span style="color:#16a34a;">Added:</span> Animation debug status now includes the current cinematic label when a cinematic is playing.
