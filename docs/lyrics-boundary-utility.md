# Pocket DJ Lyrics Boundary Utility

<span style="color:#16a34a;">Added:</span> Lyrics boundary utility controls under Dev Tools → Room utility controls.

<span style="color:#16a34a;">Added:</span> Three tunable lyric guide lines: top, middle, and bottom. Each line has X position, Y position, and width controls.

<span style="color:#16a34a;">Added:</span> Optional guide opacity control so the red boundary lines can be shown while tuning and hidden for normal use.

<span style="color:#16a34a;">Changed:</span> Lyrics now follow the tunable trapezoid shape defined by the top, middle, and bottom lines.

<span style="color:#16a34a;">Changed:</span> The active lyric is always centered on the middle guide line.

<span style="color:#16a34a;">Changed:</span> Seven lyric slots are laid out along the tuned shape, with three previous lines above, the active line in the center, and three upcoming lines below.
