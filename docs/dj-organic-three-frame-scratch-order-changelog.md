# Pocket DJ Organic Three-Frame Scratch Order Changelog

<span style="color:#16a34a;">Added:</span> Organic/random ordering for the three-frame scratch loops.

<span style="color:#16a34a;">Changed:</span> `a44`, `a47`, and `a48` loop families no longer have to move in strict order.

<span style="color:#16a34a;">Changed:</span> Three-frame scratch loops now bias back toward the base frame while randomly choosing between the accent frames. This supports patterns like `a44 → a44-3 → a44 → a44-2 → a44-3 → a44`.

<span style="color:#16a34a;">Changed:</span> The frame debug utility now shows whether the current loop uses organic/random scratch order or sequential order.
