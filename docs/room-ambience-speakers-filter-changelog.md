# Pocket DJ Room Ambience, Shadows, Speakers, and Filter Changelog

<span style="color:#16a34a;">Added:</span> Organic floor shadows below the DJ/table area so the booth and DJ feet feel grounded on the rug.

<span style="color:#16a34a;">Added:</span> Left and right room speakers as tunable visual layers.

<span style="color:#16a34a;">Added:</span> Speaker pulsing tied to active playback and demo playback.

<span style="color:#16a34a;">Added:</span> Utility controls for left speaker X, right speaker X, speaker Y, speaker scale, speaker opacity, and speaker pulse strength.

<span style="color:#16a34a;">Added:</span> Global scene filter overlay with selectable vibes: none, warm club, dreamy blue, deep night, retro VHS, neon purple, cinematic amber, and moody lowlight.

<span style="color:#16a34a;">Added:</span> Utility controls for filter strength, vignette strength, shadow opacity, and table shadow scale.

<span style="color:#16a34a;">Added:</span> LocalStorage persistence for room utility settings under `pocketdj-room-utility-v1`.

<span style="color:#16a34a;">Changed:</span> The room now has an optional unified atmosphere layer to help the DJ, background, speakers, and marquee feel more cohesive.

<span style="color:#dc2626;">Removed:</span> Nothing from the current DJ scratch animation system. This update preserves the existing organic three-frame scratch logic.
